# 桌面魔镜 使用说明

桌面魔镜是一块可以自由拖动、调整大小的矩形“镜子”：框外是你正常的桌面，框里是同一位置换成译文的桌面（译成什么语言，第一次启动时在新手指南里选）。
后台会识别并翻译**魔镜所在屏幕**上的所有可见文字（不只是框里），所以把魔镜拖到别处时，已经译好的内容会立刻出现；
拖动和缩放只改变“看哪一块”，不会重新翻译，也不会挪动译文。

网页、PDF 阅读器、文档、软件界面、游戏界面和视频字幕都用同一种方式工作，不需要专用浏览器或插件。

## 启动和退出

- **启动**：双击解压出来的文件夹里的 `DeskMirror.exe`；从源码运行时双击项目根目录的 `start.bat`（第一次使用前先运行 `setup.bat` 安装环境，见 [README](../README.zh-CN.md)）。右下角托盘出现蓝色“镜”字图标，屏幕中间出现蓝框魔镜。
  第一次启动需要几秒准备文字识别；准备期间框里先显示原文，译好的段落会一块块出现。
- **退出**：右键托盘图标 → 退出。魔镜、覆盖层和后台识别进程会一起关闭。
- **开机自动启动**（默认关）：设置 → 识别与显示 → 启动，或命令行 `config set autostart true`。登录 Windows 后魔镜收成球在屏幕边上待命，
  不截屏、不识别；点一下球或把它拖出来才开始（文字识别这时才准备，开机不拖慢）。写在 Windows 的启动项里，任务管理器的“启动应用”里也能关。
- 看日志：`start.bat debug`（带控制台窗口运行）；日志文件在 `logs\deskmirror.log`，只记录耗时和数量，不记录屏幕文字。

## 操作

| 想做的事 | 怎么做 |
|---|---|
| 移动魔镜 | 拖魔镜上方的深色标签；或**按住 Ctrl+Alt**，在镜内任意位置拖动 |
| 调整大小 | 拖蓝色边框或四个角 |
| 收起成球 | 拖着标签（或标签左头六个点的抓手）往屏幕边上走，鼠标到了边缘，魔镜缩成一个球吸在边上，**翻译停下**（都收起来时不截屏、不识别、不花 token）。松手后球藏进边缘一半，鼠标移上去会滑出来。上下左右四条边都行，只是两块屏幕相接的边不收；顶边要把鼠标顶到最上沿才收，免得把魔镜拖到菜单栏上就收起来。按住 Ctrl+Alt 在镜内拖不会收，可以把魔镜放到屏幕最边上 |
| 展开 | **点一下球**：魔镜回到收起前的地方，接着翻译。或者**按住球往外拖**：离开边缘后球变成虚线框跟着鼠标走，同时开始翻译，框里已经能看到译文，松手就落在那里；拖回边上又会收成球。收没收起、球在哪会记住，下次启动还是球 |
| 操作下面的软件 | 直接在镜内点击、选中文字、滚轮滚动——都会落到下面的软件上 |
| 临时看原文 | **按住 Ctrl+Alt+O**，松开恢复译文 |
| 刷新镜框内区域 | **Ctrl+Alt+T**，或点标签上的 ⟳（重新核对、重新识别，失败的翻译重试；不影响别处的缓存） |
| 隐藏 / 显示魔镜 | **Ctrl+Alt+H**，或点标签上的 —，或单击托盘图标 |
| 指定语言 | 点标签上的语言按钮（显示当前的语言，比如“自动→中”“英→中”），选原文和译成的语言，立即生效：换了译成的语言，已有译文全部重新翻译；原文选韩文时自动换成韩文识别模型（第一次用时下载约 14 MB），屏幕上的字重新识别。设置 → 识别与显示里也能改 |
| 看图翻译 | **Ctrl+Alt+V**，或点标签上的 **看图**（右键托盘图标也有）：把镜框里的画面（原样，不带译文）交给能看图的模型来读、来翻，结果在弹出窗口里一段段出来，可复制、重看。适合艺术字、拟声词、图片里的字、识别不出的游戏字体（漫画气泡里的竖排文字普通识别也能认，中日文译文也竖着排）。比实时翻译慢（本机模型通常几秒）。模型在 设置 → 翻译服务 → 看图翻译 里改，默认本机 Ollama 的 gemma4:12b；用云端服务时，每次发图前都会先问你 |
| 暂停 / 继续 | 点标签上的 **暂停**（右键托盘图标也有）：魔镜框留着，不截屏、不识别、不翻译（不花翻译费用），镜里也不显示译文。按钮变成黄底的 **继续**，点它恢复：先重新核对画面，看过的内容直接用缓存，不会重新请求 |
| 设置 | 标签上的 ⚙，或右键托盘图标 → 设置… |
| 新手指南、关于 | 右键托盘图标 → 新手指南… / 关于…（版本号、作者邮箱、项目主页）；第一次启动会自动打开新手指南 |
| 界面语言 | 新手指南第 1 步选母语：译文用这种语言，界面跟着用中文（选简、繁中文时）或英文（选其他语言时）。以后在 设置 → 识别与显示 → 界面语言 里改，立即生效 |
| 再开一个魔镜 | 右键托盘图标 → 新建一个魔镜，或在魔镜标签上点右键 → 新建一个魔镜（最多 4 个）；多开的魔镜可以右键标签关掉 |
| 让魔镜跟着窗口走 | 在魔镜标签上点右键 → 跟随下面的窗口：窗口移动、缩放时魔镜按相对位置跟着走，窗口最小化时魔镜收起，窗口关掉后自动取消跟随（标签上显示 📌） |
| 回看刚才的字幕、对话 | **Ctrl+Alt+Y** 打开历史面板（右键托盘图标也有）：最近在魔镜里出现过的原文和译文（最多 500 条），可搜索、复制。只在内存里，退出即清空 |
| 改一段译文 | 在历史面板里双击那一条，改好保存：这段文字现在和以后都用你改的译文（打开了译文记忆时重启后照用，否则到这次退出为止） |
| 固定人名、专有名词的译法 | 设置 → 术语表：写好原文里的词和译法，翻译时必须照用。英文等按整词匹配（art 不会匹配 start）；“只用于程序”填程序名，带不带 .exe 都行。改了术语表后，含这些词的已有译文会重新翻译 |
| 术语前后一致 | 默认打开（设置 → 术语表里可关）：翻译时附上这个窗口里含同样词语的已有译文作参考，没写进术语表的词也沿用前面的译法（比如 Employer 前面译成“雇主”，后面不会变成“业主”）。第一次出现时还没有参考，要固定的词请写进术语表 |
| 截图 | 点标签上的 **截原图**（镜框内原样）或 **截译图**（镜框内带译文，和你看到的一样），也可右键托盘图标选择。图片同时复制到剪贴板、保存到“图片\桌面魔镜”文件夹（英文界面是“Pictures\DeskMirror”），点弹出的提示可打开文件夹 |
| 用别的截图、录屏软件 | 魔镜对截屏隐身（它自己也靠截屏看字），别的软件默认截不到魔镜和译文。要用时在托盘菜单或右键魔镜标签打开 **让截图工具截到魔镜**：期间译文定住不更新，用完关掉，魔镜接着识别、翻译 |
| 看被截断译文的全文 | 译文右下角有小三角的块放不下全文，鼠标停在上面会弹出全文 |

默认快捷键可能和你电脑上的其他软件冲突：注册失败时托盘会提示，可在设置 → 快捷键里改。
按住 Ctrl+Alt 时，镜内的鼠标会用来拖魔镜，因此“Ctrl+Alt+点击”这类操作在镜内暂时不会传给下面的软件。

标签上的文字说明当前状态：“就绪”“翻译中：镜内还有 N 块”“正在识别桌面文字…”，翻译服务出错时会写明原因（例如“连不上翻译服务”）。
已识别、正在等译文的块在镜内显示一条蓝色虚线，翻译失败的显示红色虚线。

## 它是怎么跟住原文的

- **静止画面**：译文固定在原文字块的位置，盖住原文。
- **局部滚动**：程序按实际画面变化判断哪一块区域在整体平移（不只看滚轮），把它当成独立的“滚动画布”。
  同一窗口里可以有多块（例如 MDN 文档的侧栏和正文）；固定的标题栏、导航、侧栏不会跟着动。
  页面里有正在播放的视频、动画时照样能认出滚动（视频跟着页面走，画面本身的变化不影响判断）；
  有别的窗口或网页弹窗压在上面、把变化区域切成几块时，按同一次滚动处理，不会把译文移两遍。
  滚出去的译文留作缓存，滚回来核对一致后直接复用，不再调用翻译服务。
- **先找再丢**：某一段在预测的位置对不上时，先沿滚动方向在附近按整段的样子找一找，像素完全一致就把译文挪过去；
  找不到才隐藏、重新识别。重新识别时只是把已有段落换了一种分组（几行合成一段、一段拆成几行）、像素又没变的，
  保留原来的译文，不重新翻译。
- **滚轮提前量**：程序被动接收滚轮（不装钩子），按每个软件学到的“每格多少像素、动画曲线”提前移动译文，
  让译文和原文同步起步；画面核对始终是最终依据，对不上就自动停用预测。
  学到的曲线存在配置旁的 `deskmirror_wheel.json`（只有数字），下次启动直接可用。
- **按速度提前**：键盘翻页、拖滚动条、触控板，或还没学到曲线的滚轮，滚动途中按最近两帧测得的速度和减速，
  把译文提前放到“显示出来那一刻”原文所在的位置；正在减速时最多推到预计停下的位置，一停下立即撤回。
- **被挡住一部分的段落**：网页上的弹窗、浮层、提示框挡住了一段文字的一部分时，只核对露出来的部分；
  这段保留原来的整段译文，按可见范围裁掉被挡的部分，不会被换成半句重新翻译。
- **滚动途中先不识别**：正在滚动的区域停下 0.15 秒后才识别新露出的内容，免得识别结果一出来就过时。
- **窗口移动、遮挡、改大小**：窗口移动时译文跟着走；被别的窗口挡住的部分不画；窗口改大小导致重新换行时，
  对不上的译文先隐藏，重新识别后补上。
- **网页、文档里原文变了**：旧译文立即撤下，重新识别、翻译。
- **字幕和游戏对话的上下文**：翻译新的一句时，带上同一窗口 30 秒内的前 3 句（原文和译文），人称、语气更连贯。
- **视频字幕、游戏画面这类一直在动的区域**：按文字笔画判断字还在不在；字幕换句时，旧译文先保留，
  新句子的译文一到直接顶掉（最多保留 4 秒；字幕消失则撤下）。只有文字后面的底真的是花的（视频、游戏场景），
  译文才用深色底板白字；网页、文档上的字始终用原来的底色。

识别和翻译的顺序：先补齐魔镜内部，再处理镜框外一圈，然后一圈圈向外，直到整块屏幕；没变的内容不重复识别和翻译。

## 翻译范围与隐私

设置 → “范围与隐私”（托盘右键菜单里也有“预译范围”和“不翻译魔镜下的这个程序”）：

- **预译范围**：
  - **整块屏幕**（默认）：魔镜所在屏幕上看得见的文字都在后台预先翻译，拖到哪里都能立刻看到译文；
    但别的窗口里的文字也会发给翻译服务。
  - **只翻魔镜所在的窗口**：只翻魔镜里露出来的那几个窗口，其余等魔镜移过去再翻。
  - **只翻镜框附近**：只翻镜框外一定距离（默认 480 像素）以内的段落。
  - 用云端服务又在意隐私或花费时，建议选后两种。
- **不翻译的程序 / 窗口标题**：
  - 默认已排除聊天软件（微信、QQ、企业微信、钉钉、飞书、Telegram、WhatsApp、Discord 等）和密码管理器；
    标题含“网上银行、网银、支付宝、PayPal”等词的窗口也排除。
  - 名单里的窗口在送去识别之前就被涂掉：不识别、不翻译，不会发给任何翻译服务。
  - **翻译聊天软件**（默认关）：和外国同事、朋友聊天时，右键魔镜的标签或托盘菜单勾选它，名单里的聊天软件就照常翻译（聊天内容会发给翻译服务；用本机 Ollama 则不出本机），聊完再关掉。密码管理器和网银、支付页面始终不翻。设置 → 范围与隐私 里也有同一个开关。
  - 魔镜里有这类窗口时，标签上会注明。
- **用量**：魔镜标签上的 `↑12.3k ↓4.1k` 是今天发给翻译服务的 token（↑ 输入、↓ 输出），鼠标停上去看明细（服务、模型、请求数、命中服务商缓存的部分）；托盘图标的提示和设置页也有。服务没报用量的部分按字数估算，标“≈”。
  每次请求还会在 `logs/usage-年-月.jsonl` 记一行（只有数量和程序名，不记屏幕上的字），命令行 `usage --log` 按程序、批大小、小时汇总。
- **省钱保护**：
  - 超过一段时间（默认 5 分钟）没碰键盘鼠标，就只翻镜框里的文字，不在后台预译别处（动一下就恢复）；镜框里的字幕照常翻译。
  - 锁屏、屏保时完全停下（不截屏、不识别、不翻译）。
  - 云端服务一天最多用多少 token（默认 100 万，输入 + 输出）：到了就停止翻译新文字，已有译文照常显示，第二天自动恢复；本机 Ollama 不限。
  - 已有请求在途时，零星的新文字最多等 0.6 秒凑成一批再发：每次请求都带约 430 token 的固定说明，一两行字单独发很不划算。
  - 余额不足（HTTP 402）时标签上会说清楚，停下等你充值。
- **译文记忆**（默认关闭）：打开后，译文用当前 Windows 账户加密存在本机，下次遇到相同的文字直接用，省时间也省费用；
  可随时在设置里清空（记忆关着时点清空，也会删掉以前存下的文件）。只有数字不同的文字（计时器、进度、血量、“3 天前”）不管开不开，都会套用已有译文、换上新数字，
  不再请求翻译服务。

## 翻译服务设置

设置 → “翻译服务”：

- **接入方式**：`Ollama 原生接口`（默认，本机 `http://127.0.0.1:11434`，模型 `gemma4:12b`，免费、不出本机），
  或 `OpenAI 兼容接口`（DeepSeek、通义千问、硅基流动、OpenAI、LM Studio 等，“常用服务”下拉可一键填入地址）。
- **模型**：可手填，或点“获取模型列表”：取到后自动展开下拉框；没取到会写明原因（比如密钥不对、地址没有这个接口）。
- **API Key**：云端服务才需要；只用当前 Windows 账户加密（DPAPI）保存在本机 `deskmirror.json`，不写进源码、版本库和日志。
- **测试连接**：发一句短文，显示是否成功、用时和译文。
- **同时请求 / 超时**：本地模型建议 1 个；云端服务可以调到 2~3 个。
- 本地 Ollama 请用“Ollama 原生接口”：通过 OpenAI 兼容接口（/v1）调用时无法关闭模型的“思考”，gemma4 一次要十几秒。
- 用云端服务时，屏幕上识别出的文字、所在窗口的标题、这些文字里用到的术语表条目，以及作为参考附上的同一窗口里已译过的文字，会发送给该服务。
- 看图翻译发的是镜框里的截图（看得见的都会发出去），只在你按了快捷键或点了“看图”时才发；发给本机以外的服务前每次都先问你。

其他设置：原文和译成的语言（默认自动识别 → 简体中文，也可以用标签上的语言按钮改）、文字识别用显卡或 CPU（玩游戏时可改 CPU，不和游戏抢显卡）、
是否处理所有屏幕（默认只处理魔镜所在的屏幕）、滚轮预测开关、最小字号、底板不透明度、快捷键。
识别设备、屏幕范围和滚轮预测的更改在下次启动时生效。

## 默认参数（可在 deskmirror.json 里调整）

一般不需要改。可以用命令行改（见下一节），也可以直接编辑这个文件：正在运行的魔镜一秒内自动载入。

| 参数 | 默认 | 含义 |
|---|---|---|
| `track.stable_ms` | 350 | 区域静止多久后才识别新文字（快速滚动时先不识别） |
| `track.dynamic_ms` | 1000 | 魔镜附近一直在动的区域（字幕、游戏）多久抓拍识别一次 |
| `track.subtitle_hold_ms` | 4000 | 字幕换句时旧译文最多保留多久 |
| `track.ring_px` | 240 | 螺旋调度每一圈的宽度 |
| `track.max_cache_blocks` / `max_cache_texts` | 6000 / 20000 | 文字块缓存、译文缓存上限（只在内存里） |
| `track.display_lead_ms` | 12 | 滚轮预测的提前量（绘制 + 一帧合成） |
| `llm.max_batch_items` / `max_batch_chars` | 10 / 1000 | 一次请求最多合并几个文字块、多少字（实测 8~10 块吞吐已到顶） |
| `llm.timeout_s` / `concurrency` | 45 / 1 | 请求超时、同时请求数 |
| `style.min_font_px` / `min_scale` | 11 / 0.75 | 放不下时最多缩到 11 像素或原字号的 75%；右边有纯色空白就向右借（中日文译成英文常需要，不越过右边的字、不盖图片），再放不下就向下占用空白；下面是面板边框、图片或在动的画面时先再缩小一些（最小到原字号的六成），还放不下才盖过去，仍放不下截断并标出；英文单词尽量不拆开 |
| `style.min_squash` | 0.6 | 英文等放不下时最多横向压扁到原宽的 60%：先压到八成（几乎看不出来）再缩字号；更扁的只在快要伸出面板、要缩得更小时才用。中日韩文字最多压到八成 |
| `style.plate_opacity` | 1.0 | 底板不透明度（1 = 完全盖住原文） |

## 命令行（让 AI 帮你设置）

所有设置都能用命令行查看、修改，脚本和 Claude Code、Codex 这类 AI 助手都能用。下载版用 DeskMirror 文件夹里的
`DeskMirrorCLI.exe`，源码版用 `.venv\Scripts\python -m deskmirror`：

| 命令 | 作用 |
|---|---|
| `config keys` | 每项设置的说明、能取的值、改了要不要重启（`config schema`：同样的内容，输出 JSON） |
| `config list` / `config get 名字` | 查看全部 / 一项设置（API Key 只显示前后几位） |
| `config set 名字 值 [名字 值…]` | 改设置；超出范围、格式不对会报错，不会悄悄改成别的值。值写 `-` 从标准输入读，写 `--env 变量名` 从环境变量读（API Key 这样传，不留在命令行里） |
| `config reset 名字` | 恢复默认值 |
| `service [服务名]` | 列出预设的翻译服务，或换成其中一个：deepseek、qwen、siliconflow、openai、ollama、ollama-openai、lmstudio |
| `models [--vision]` | 翻译服务（或看图翻译服务）现有的模型 |
| `test` | 发一句短文试试翻译服务 |
| `glossary list` / `add 原文 译文 [--app 程序.exe]` / `remove 原文` | 管理术语表 |
| `usage` / `usage --log [日期]` | 今天的请求数、字数、token / 按每次请求的日志汇总一天（哪个程序、多大的批、命中缓存多少） |
| `status` | 版本、配置文件在哪、魔镜在不在运行、能怎么更新 |

加 `--json` 输出 JSON（只用 ASCII，给程序读；出错时 `"ok": false`，返回码不是 0）。改的是 `deskmirror.json`：
正在运行的魔镜一秒内自动载入，托盘会提示一下；识别设备、截屏方式、屏幕范围和滚轮预测要重启才生效，命令会说明。

## 更新到新版本

- 托盘菜单“检查更新…”，或设置 → 关于 →“检查更新”：有新版本就显示更新说明。点“下载并更新”后下载、核对（SHA256），
  然后魔镜退出、换上新版本、自动重新打开；设置、日志、学到的滚轮曲线、译文记忆都留着。中途出错会换回旧版本。
- 启动后每天最多自动查一次（只向 GitHub 查版本号和更新说明，不发送屏幕内容），有新版本只在托盘提示一下，点了才打开
  检查更新的窗口；不想要可以在设置 → 范围与隐私里关掉，或在窗口里点“跳过这个版本”。
- 源码版（用 git clone 下载的）：点“更新（git pull）”，魔镜退出后拉取新代码、重装依赖、重新打开。改过代码就不自动更新。
- 命令行：`update --check` 查有没有新版本，`update --yes` 下载并换上（正在运行的魔镜会自动退出、重新打开）。
- 魔镜放在 Program Files 这类不能写入的文件夹里时没法自动更新，请到发布页下载，解压覆盖。

## 恢复默认设置、卸载

- **恢复默认设置**：退出魔镜，删除程序文件夹（解压出来的文件夹，从源码运行时是项目根目录）里的 `deskmirror.json` 再启动（API Key 也会被清除，需要重新填写）。
- **卸载**：退出魔镜，删除整个程序文件夹即可。它不改动系统设置；如果打开过开机自动启动，先在 设置 → 识别与显示 里关掉
  （或命令行 `config set autostart false`），不然 Windows 的启动项里会留下一条找不到程序的记录。

## 已知限制

- 目前只在一台电脑上测试过：Windows 11、主屏 3840×2160 / 100% 缩放、RTX 4090。副屏（2560×1600 / 125%）只验证过“魔镜拖过去会切换并开始识别”。其他缩放比例、显卡和 Windows 10 还没测过，欢迎反馈。
- 独占全屏的游戏、受保护的画面（DRM 视频等）无法覆盖或截取；游戏需改用无边框或窗口化。真实游戏尚未实测，只用模拟游戏画面和字幕的测试页验证过。
- 像素字、艺术字、很小的字可能识别错，译文随之出错。竖排文字要像漫画气泡那样一列列排整齐才认得好，斜着排的拟声词请用看图翻译。本地 12B 模型偶尔会把 CSS 属性名这类单词也翻译掉。
- 能识别英文、中文、日文、印尼文等；韩文要在语言按钮里选“原文：韩文”（换用韩文识别模型，认不了中文、日文）。
- 页面缩放（Ctrl+滚轮）、整页刷新、展开折叠等会被当成内容变化：先隐藏、再重新识别，有短暂的原文闪现。
- 快速拖动窗口时，译文可能短暂隐藏，停下后恢复。
- 新出现的文字需要识别 + 翻译的时间（本地模型约 1~3 秒），滚动途中译文和原文会有几个到几十个像素的错位（停稳后精确对齐）。
- 魔镜自身的标签和设置窗口不随 125% 缩放放大。
