# DeskMirror（デスクミラー）

Windows 用の画面翻訳ツールです。デスクトップの好きな場所にドラッグできる「ミラー」を置くと、枠の中では同じ位置の文字が
その場で訳文に置き換わり、枠の外はいつものデスクトップのままです。
Web ページ、PDF、アプリ、ゲーム、動画の字幕がすべて同じやり方で翻訳でき、ブラウザー拡張機能も要りません。

![ミラーをゲームの会話ウィンドウに重ねると、日本語が英語に置き換わる](docs/images/hero-en.gif)

はじめての方は[クイックスタート](docs/QUICKSTART.en.md)（初回起動時にも同じガイドが開きます）と
[ユーザーガイド](docs/GUIDE.en.md)をどうぞ（どちらも英語です。中国語版もあります）。

## 特長

- **その場に表示**：訳文は原文があった位置に、なるべく同じ文字サイズ・色で表示されます。Ctrl+Alt+O を押している間は原文が見えます。
- **画面の動きについていく**：スクロール、ウィンドウの移動や重なり、動画の字幕にも追従します。画面の変化を見て判断するので、特定のアプリには依存しません。
- **バックグラウンドで先に翻訳**：ミラーがある画面の文字を前もって翻訳しておくので、どこへドラッグしても訳文がすぐ出ます。一度翻訳した内容は二度と翻訳しません。
- **翻訳サービスを選べる**：ローカルの [Ollama](https://ollama.com)（無料、文字が PC の外に出ません）、または DeepSeek、Qwen、OpenAI など OpenAI 互換 API。
- **プライバシーを自分で管理**：翻訳しないリスト（チャットアプリ、パスワード管理ソフト、ネットバンキングは既定で除外。海外の同僚や友人とチャットするときは「Translate chat apps」をワンクリックでオン）、3 段階の先読み範囲、当日の使用量の表示。画面の文字は既定ではディスクに保存しません。
- **言語をいつでも切り替え**：ミラーのタブにある言語ボタン（例：「Auto→JA」）で原文と訳文の言語を指定できます。中国語、英語、日本語、韓国語、インドネシア語に対応しています。
- **英語と中国語のインターフェース**：初回起動時に母語を選ぶと、訳文はその言語で表示されます。画面表示（UI）は中国語と英語のみで、日本語を選んだ場合は英語になります。どちらも後から設定で変更できます。
- **用語集**：用語集の訳語は必ず使われ、登録していない言葉もできるだけ訳を揃えます。字幕やゲームの会話は直前の数行を文脈として渡すので、人称や口調が揃います。
- **収まるように配置**：訳文が原文より長いときは、まず少しだけ横に詰め、次に近くの空白を借り、それでも収まらないときに文字を小さくします。パネルの枠や画像、動画の上にはみ出しません。
- **漫画**：吹き出しの縦書き文字をそのまま認識します。中国語・日本語の訳文は縦書きのまま元の位置に入り、英語は吹き出しの中央にそろえます。
- **画像翻訳**：Ctrl+Alt+V を押すか、タブの「Image」をクリックすると、枠の中の画面を画像を読めるモデル（既定は Ollama の gemma4:12b）に渡して読み取り・翻訳します。デザイン文字、擬音、画像の中の文字に向いています。
- **ボールにしまう**：ミラーを画面の端までドラッグすると、ボールに縮んで端にくっつき、翻訳を止めます。引き出せば、放した場所で翻訳を続けます。
- **入力欄の翻訳**：ほかのアプリの入力欄でスペースを 3 回続けて押す（または Ctrl+Alt+J）と、母語で打った文を外国語に置き換えます。もう一度押すと元に戻ります。既定はオフ。
- **リキッドグラスのスキン**（任意）：枠が後ろの画面を屈折させる曲面ガラスの輪になり、タブとボールもガラスになります。
- ほかにも：履歴パネル、訳文の修正、複数のミラー、ウィンドウに追従するミラー、一時停止、スクリーンショット、Windows と一緒に起動、アプリ内アップデート。

## インストール

必要なもの：

- Windows 11（Windows 10 でも動くはずですが、まだ試していません）
- 翻訳サービス（どちらか一つ）：
  - ローカル：[Ollama](https://ollama.com) をインストールし、`ollama pull gemma4:12b` を実行（モデルは約 7.6 GB。ビデオメモリの多い単体 GPU が必要）
  - クラウド：DeepSeek などのサービスの API キー（従量課金）

### ダウンロードしてすぐ使う（おすすめ）

1. [Releases](https://github.com/Yudreamsky/deskmirror/releases/latest) から `DeskMirror-<バージョン>-win64.zip`（約 140 MB）をダウンロードします。
2. 書き込みできる好きなフォルダー（「ドキュメント」や D ドライブなど）に展開し、中の `DeskMirror.exe` をダブルクリックします。あとはガイドに沿って設定するだけです。
   - 「Windows によって PC が保護されました」と表示されたら（コード署名をしていないため）、「詳細情報」→「実行」をクリックしてください。
   - 設定とログはこのフォルダーに保存されます。新しいバージョンは同じ場所に上書きで展開すれば、設定はそのまま残ります。
   - C:\Program Files には展開しないでください（設定を書き込めず、`%LOCALAPPDATA%\DeskMirror` に保存されます）。
3. Python は不要です。文字認識モデル（韓国語を含む）はパッケージに入っています。

### ソースから実行する

1. [Python 3.12](https://www.python.org/downloads/) をインストールします（インストール時に「Add python.exe to PATH」にチェック）。
2. コードを取得します：`git clone https://github.com/Yudreamsky/deskmirror.git`、または GitHub から ZIP をダウンロードして展開。
3. `setup.bat` をダブルクリックします。`.venv` を作り、依存パッケージ（PySide6、RapidOCR、ONNX Runtime など）をインストールします（ネット接続が必要）。
4. `start.bat` をダブルクリックします。文字認識モデルはパッケージと一緒に入ります。韓国語のモデル（約 14 MB）は、初めて「Original: Korean」を選んだときに自動でダウンロードされます。
5. exe を自分でビルドするには：`.venv\Scripts\python -m pip install -r requirements-build.txt` のあと `.venv\Scripts\python packaging\build.py`。

クラウドのサービスを使うには：ガイドのステップ 3 で「Cloud service」を選ぶか、ミラーのタブの ⚙ → Translation service で
「OpenAI-compatible API」を選び、アドレス、モデル、API キーを入力して「Test connection」をクリックします。

文字認識は既定で GPU（DirectML。DirectX 12 対応のグラフィックボードならどれでも）を使い、使えない場合は自動で CPU に切り替わります。

## 使い方

初回起動時にガイドが開きます（ステップ 1 で母語を選択。あとからタスクトレイのメニューでいつでも開けます）。
詳しくは[クイックスタート](docs/QUICKSTART.en.md)と[ユーザーガイド](docs/GUIDE.en.md)をご覧ください。よく使う操作：

| やりたいこと | 操作 |
|---|---|
| ミラーの移動・サイズ変更 | ミラー上部のタブをドラッグ／青い枠をドラッグ |
| 原文をちょっと見る | Ctrl+Alt+O を押している間 |
| ミラーの表示／非表示 | Ctrl+Alt+H |
| ミラーをボールにしまう | タブを画面の端までドラッグ。ボールをクリックすると元に戻る |
| 打った文を外国語に置き換える | 入力欄でスペースを 3 回、または Ctrl+Alt+J（Settings → Text boxes でオンに） |
| リキッドグラスの見た目 | Settings → Recognition and display → Skin |
| さっきの字幕や会話を見返す | Ctrl+Alt+Y で履歴パネル |
| 一時停止（枠は残し、認識も翻訳もしない） | タブの「Pause」をクリック |
| 言語の指定（例：EN→JA、ZH→JA、KO→JA） | タブの言語ボタンをクリック |
| チャットアプリも翻訳する（海外の友人とのチャット） | タブかトレイアイコンを右クリック →「Translate chat apps」 |
| 画像翻訳（漫画、デザイン文字、画像の中の文字） | Ctrl+Alt+V、またはタブの「Image」 |
| 設定 | タブの ⚙、またはトレイアイコンを右クリック |
| 新しいバージョンに更新 | トレイアイコンを右クリック →「Check for updates…」 |

### 使用量と節約

- ミラーのタブの `↑12.3k ↓4.1k` は、今日翻訳サービスに送ったトークン数です（↑ 入力、↓ 出力）。マウスを乗せると、プロバイダーのキャッシュに当たった分も含めた内訳が表示されます。
- どのリクエストにも約 430 トークンの固定の指示が付くので、細かいリクエストを減らすのがいちばんの節約です。応答待ちのリクエストがある間に出てきた細切れの新しい文字は、少し待ってからまとめて送ります。先読み範囲は「Whole screen」より「Only the window under the mirror」や「Only near the frame」のほうがずっと安く済みます。
- しばらくキーボードとマウスに触れないとミラーの中の文字だけを翻訳し、画面のロック中やスクリーンセーバーの実行中は完全に止まります。クラウドのサービスは既定で 1 日 100 万トークンまでで、上限に達すると止まります。いずれも設定の「Scope and privacy」で変えられます。
- リクエストごとに `logs/usage-YYYY-MM.jsonl` に記録します（件数とプログラム名だけで、画面の文字は記録しません）。コマンドラインの `usage --log`（次の節を参照）で、プログラム別・リクエストの文字数別・時間別に集計できます。

## AI に設定してもらう

すべての設定はコマンドラインからも変更できるので、Claude Code や Codex のような AI アシスタントに設定を丸ごと任せられます。起動中の DeskMirror は変更を 1 秒以内に反映します。

- ダウンロード版：DeskMirror フォルダーの `DeskMirrorCLI.exe`。ソースから実行する場合：`.venv\Scripts\python -m deskmirror`。
- `config keys` で各設定の説明と取りうる値を一覧表示し、`config list`・`config get`・`config set`・`config reset` で確認・変更します。`service`・`models`・`test` で翻訳サービスの切り替え、モデルの一覧表示、動作確認ができ、`usage` で今日使ったトークン数、`status` で DeskMirror が起動中かどうかがわかります。`--json` を付けると JSON で出力します。
- API キーは標準入力（`config set llm.api_key -`）か環境変数（`config set llm.api_key --env DEEPSEEK_API_KEY`）から読み込みます。コマンドラインには残りません。Windows アカウントで暗号化して保存し、表示は常に `sk-…1234` の形です。

たとえば DeepSeek に切り替えて日本語に翻訳するには：

```bat
DeskMirrorCLI.exe service deepseek
DeskMirrorCLI.exe config set llm.api_key -
DeskMirrorCLI.exe config set target_lang ja first_run_tip false
DeskMirrorCLI.exe test
```

（2 行目で API キーの貼り付けを求められます。入力した文字は表示されません。）AI アシスタントにこう頼んでもかまいません：

> DeskMirror を設定してください。D:\DeskMirror にあります。まず `DeskMirrorCLI.exe --help` と `DeskMirrorCLI.exe config keys --json` で設定できる項目を確認してください。翻訳サービスは DeepSeek（API キーは渡すので `config set llm.api_key -` で設定）、日本語に翻訳し、最後に `DeskMirrorCLI.exe test` で動作を確認してください。

## プライバシー

- クラウドの翻訳サービスを使う場合、画面から認識した文字とウィンドウのタイトルがそのサービスに送信されます。気になる場合はローカルの Ollama を使うか、設定で先読み範囲を狭めたり、翻訳しないプログラムを追加したりしてください。
- API キーは Windows アカウントで暗号化（DPAPI）され、この PC の `deskmirror.json` に保存されます。
- ログに記録するのは所要時間と件数だけで、画面の文字は記録しません（リクエストごとの使用量ログには、文字があったプログラムの名前も記録します）。「Remember translations」は既定でオフで、オンにした場合のみ訳文を暗号化してこの PC に保存します。
- 画像翻訳では、枠の中のスクリーンショットを設定した画像対応モデルに送ります。既定はローカルの Ollama なので画像は PC の外に出ません。クラウドのサービスに変えた場合は、送信のたびに確認します。
- 更新の確認：起動後 1 日に 1 回まで、GitHub に最新バージョンの番号と更新内容を問い合わせます。画面の内容は送りません。ダウンロードはクリックしたときだけです。設定の「Scope and privacy」でオフにできます。

## 既知の制限

- テストしたのは今のところ 1 台の PC だけです（Windows 11、3840×2160 / 拡大率 100%、RTX 4090）。
- 排他的フルスクリーンのゲームや、著作権保護された動画の画面には重ねられず、キャプチャもできません。ゲームはボーダーレスかウィンドウモードでお使いください。
- デザイン文字、ドット文字、ごく小さな文字は誤認識することがあります。縦書きは漫画の吹き出しのように列がきちんとそろっていれば読めますが、斜めに書かれた擬音は画像翻訳をお使いください。韓国語は言語ボタンで「Original: Korean」を選んでください（韓国語用の認識モデルに切り替わります）。
- 詳しくは[ユーザーガイド](docs/GUIDE.en.md#known-limitations)をご覧ください。
